glance-first: a new skill that presents any piece of work so a reader gets the key information in
under one minute: the answer, the key numbers, then at most four blocks that each open on a diagram.
A Node script checks the brief before it is drawn as an artifact page, a pull request body, terminal
text or a Markdown file. Ships its four Diataxis pages and an eval.

doc-compass: every page now opens glance-first (the answer line, the key numbers, then a picture
before the prose), written with the glance-first skill when it is installed.
