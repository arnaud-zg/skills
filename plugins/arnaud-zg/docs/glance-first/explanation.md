Explanation**

Why the skill works the way it does. To get something done, see the [How-to guides](how-to.md).

## A reader decides in the first line whether to keep going

Most readers of a summary stop early. So the first line is the answer, not a lead-in, and everything
after it is proof they may skip.

## A figure says how much, faster than a sentence

"The build is faster" asks to be believed; "`12 → 3` minutes" does not. The numbers sit right under
the answer so the size of the change is the second thing seen. A digit is required in every value so
a word like "many" cannot pass as a figure, and an empty list must be written on purpose.

## The eye goes to a picture before it reads

A diagram that marks `NEW:` lands faster than the sentence describing it. So each block draws its
picture first, and the first block must have one. The line under it only says what the picture
proves.

## A script holds the limits, not good intentions

Word caps, the 200-word budget and the reading order drift when only a writer watches them. The
check refuses a brief that breaks one and says the fix, so the minute is held every time.
