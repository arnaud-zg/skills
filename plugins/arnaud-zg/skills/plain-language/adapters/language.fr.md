# language · fr

**ASD-STE100 has no French version.** Apply its writing rules. Skip its dictionary.

- Write the steps in the imperative: "Lancez le test", not "Il faut lancer le test".
- Use "pour", not "afin de". Use "vous", not "on", when the reader acts.
- Avoid the passive with "être": "Le script lit le fichier", not "Le fichier est lu par le script".
- Keep the English word when the project uses it: "commit", "pull request", "merge".
