# The rules

**Seven rules from ASD-STE100, plus one that keeps what is not known.** The script checks the rules
marked "script". Check the others yourself before you hand over.

| #   | Rule                                                   | Checked by      | Before                                                                                      | After                                                |
| --- | ------------------------------------------------------ | --------------- | ------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 1   | Stay under the word limit of the level                 | script          | "We should consider removing the approval step, since it adds friction for every new user." | "Remove the approval step. It slows every new user." |
| 2   | Write one idea per sentence. No `;`                    | script          | "The cache is faster; it also fixes stale reads."                                           | "The cache is faster. It also fixes stale reads."    |
| 3   | Use the active voice                                   | hint            | "The file is deleted by the script."                                                        | "The script deletes the file."                       |
| 4   | Use one term for one thing                             | you             | "the check… the linter… the validator"                                                      | "the check… the check… the check"                    |
| 5   | Write steps as a numbered list. Start each with a verb | script (strict) | "1. The tests should then be run."                                                          | "1. Run the tests."                                  |
| 6   | Write no filler                                        | script          | "It's worth noting that this is really just a rename."                                      | "This is a rename."                                  |
| 7   | Put the condition first                                | you             | "Stop if the check fails."                                                                  | "If the check fails, stop."                          |
| +   | Say what is not known, once                            | you             | "This might possibly be somewhat slower."                                                   | "Not measured. It may be slower."                    |

## What stays as it is

- Code, commands, paths, names and numbers.
- Quotes from a source. A quote is copied, not written.
- Technical words of the project. STE allows them. Keep one meaning for each.
- The language of the reader. A French request gets a French answer.

## What the rules do not ask

- They do not ask for the STE dictionary. It has no software words, and it exists only in English.
- They do not remove a reason. Write "because" in its own sentence: "Keep the step. The law asks for
  it."
