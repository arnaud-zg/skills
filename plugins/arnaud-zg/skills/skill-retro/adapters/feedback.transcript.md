# feedback: the transcript

The session itself is the richest record. Walk it once, in order, and note each moment below against
the skill whose step was being followed at the time.

| Look for                                                           | Kind        | Evidence to copy                 |
| ------------------------------------------------------------------ | ----------- | -------------------------------- |
| the person corrects, repeats an instruction or says stop           | `wrong`     | their words, quoted              |
| the same command or step run again after a misread                 | `wrong`     | both runs, one line each         |
| a tool error, a refused hook, a permission refusal, a failed check | `wrong`     | the error line                   |
| a wait, a poll or a long job that a step could have avoided        | `slow`      | the command and how long it took |
| a page read and not used, or read twice                            | `expensive` | the page's path                  |

A moment that no skill's step caused is not a finding for this retro.
