# feedback: memory notes

A feedback note the session wrote or changed is a correction that lives outside the skill it
corrects. It is loaded every session, and the skill still says the old thing.

For each such note that names how a skill should behave:

- It is a `wrong` finding against that skill. The evidence is the note's name and its rule line.
- The fix moves the rule into the skill, in the one page whose reader needs it. Once that fix is
  merged the note can be cut: say so in the pull request, and leave the note alone until then.

A note about the person, the project or a tool, and not about a skill, is not a finding.
