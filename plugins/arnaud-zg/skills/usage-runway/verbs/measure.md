# measure

**Check before every dispatch, alongside the clock.** Not once at the start (why: E-01).

## 1 · Ask

```bash
node ${CLAUDE_SKILL_DIR}/scripts/credit.mjs [--need <minutes>] [--json]
```

| Pass               | To learn                                                   |
| ------------------ | ---------------------------------------------------------- |
| nothing            | the window: when it opened, what it burned, when it resets |
| `--need <minutes>` | whether one unit of work of that length fits: GO or PARK   |
| `--json`           | the same report, for another script                        |

It reads the turns and limit hits the ledger port recorded in the last two days, finds the current
window (`domain/rules.md` § _The window is not_), and prints `screens/runway.md`. **Every project on
the machine counts**, because the limit belongs to the account.

## 2 · Act on the word

| It says  | The caller                                                                                                   |
| -------- | ------------------------------------------------------------------------------------------------------------ |
| **GO**   | starts the unit                                                                                              |
| **PARK** | stops at this boundary, prints the reset time it is waiting for, and says how long it waited once it resumes |

`domain/rules.md` § _The decision_ has the arithmetic and the rules the caller keeps.

## Ends

On the verdict line, which is the last line printed. The caller takes it in the same breath.
