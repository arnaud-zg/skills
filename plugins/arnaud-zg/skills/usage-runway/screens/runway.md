# runway

**Every number carries its honesty in brackets, and the last line is the decision.**

```
credit · 5h window opened 19:26 · 660 turns
  burned    4.0M billed  (measured)
  week      151.8M billed in 7 days  (measured)
  resets    00:26 · 3h49 left  (projected from the window start)
  GO  3h49 of window against 45m needed
```

While a limit is in flight the reset line reads `(exact, a limit was hit)` and the verdict is
`PARK  a limit was hit; it lifts at <time>`.
