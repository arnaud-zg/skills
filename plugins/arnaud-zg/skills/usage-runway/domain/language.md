# Language

| Term        | Means                                                                          |
| ----------- | ------------------------------------------------------------------------------ |
| **window**  | the rolling stretch of time the usage limit is counted over, five hours so far |
| **burn**    | the tokens this window's turns were billed, summed, and printed for reading    |
| **reset**   | when the window ends, or when a limit that was hit lifts                       |
| **unit**    | one piece of work the caller is about to start, sized in minutes               |
| **margin**  | the `x 1.5` on every estimate: what work takes when something goes wrong       |
| **verdict** | the one word the meter ends on: GO or PARK                                     |
