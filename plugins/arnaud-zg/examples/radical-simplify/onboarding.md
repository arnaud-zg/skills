# Onboarding, radically simpler

## Question

Does a new user need an account before they see the product? No: they need to see it work.

## Remove

Drop the survey, the tour and the email check from the first run.

## Simplify

One screen: a name field and a start button.

## Reimagine

Start in a sample workspace; ask for the account when they save.

## Accelerate

The sample loads from cache, under one second.

## Automate

The welcome email is sent when they save, not typed by support.
